AL HUDA eQURAN ACADEMY - PERFORMANCE FIXES

This version keeps the existing design/functionality but applies targeted mobile performance fixes:

1. Hero slider:
   - First slide is active in the HTML immediately.
   - First slide is preloaded with fetchpriority=high.
   - Width/height attributes added to reduce layout work.
   - Slider transition limited to opacity/transform.
   - Slider rotation starts after the initial render.

2. Feature images:
   - Resized from 1254x1254 to 400x400 because the site displays them around 220px.
   - loading="lazy" remains enabled so they do not compete with above-the-fold content.

3. Navigation logo:
   - Resized from 1254x1254 to 256x256.

4. Main/content images:
   - Large content/course images were resized to more reasonable maximum dimensions while keeping WebP.

5. Google Fonts and Font Awesome:
   - Changed to non-blocking preload + stylesheet loading so they do not block the initial render.

IMPORTANT:
- Test this build on Netlify and PageSpeed Mobile before making further changes.
- If the design is visually different on any device, restore the previous ZIP and revert only the affected change.
